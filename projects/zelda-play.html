🗡️ Zelda II — Joue directement ici

Le jeu tourne entierement dans ton navigateur grace a Pyodide (Python compile en WebAssembly) : aucun serveur, aucune installation, tout s'execute en local sur ta machine.

Chargement de l'environnement Python (Pyodide)...
Z Q S D — se deplacer Espace — sauter en combat M — attaquer C — s'accroupir Entree — parler aux PNJ Esc — quitter

Clique dans le terminal avant de jouer pour qu'il capte tes touches. Recharge la page pour recommencer une partie.
