📖 À propos du projet

Ce projet a été développé dans le cadre de la SAE201 - Développement d'une application au second semestre du BUT Informatique. Il s'agit d'une application desktop en C# utilisant Visual Studio et mettant en pratique les concepts de programmation orientée objet, les patterns de conception et les bonnes pratiques de développement.

📦 Programmation Orientée Objet

Architecture logicielle utilisant les principes SOLID, l'encapsulation, l'héritage et le polymorphisme.

🏗️ Architecture Logicielle

Conception d'une architecture modulaire et maintenable avec séparation des responsabilités.

🖥️ Interface Utilisateur

Développement d'une interface desktop moderne et intuitive avec .NET Framework.

🎨 Design Patterns

Implémentation de patterns de conception pour une meilleure structuration du code.

🧪 Tests et Débogage

Mise en place de tests unitaires et gestion des erreurs avec des pratiques de débogage.

🔀 Gestion de Version

Utilisation avancée de Git pour le versioning et la traçabilité du code.

Contexte Pédagogique

La SAE201 - Développement d'une application est un projet majeur du second semestre du BUT Informatique. Il permet de consolider les compétences en développement logiciel avec un focus sur la programmation orientée objet, la conception d'architecture et l'implémentation de fonctionnalités complexes dans un environnement de développement professionnel.

🎯 Concepts de POO Mis en Pratique

🔒 Encapsulation

Protection des données avec des modificateurs d'accès et des propriétés pour un code plus sûr.

🧬 Héritage

Hiérarchie de classes pour la réutilisation du code et l'extension des fonctionnalités.

🎭 Polymorphisme

Méthodes virtuelles et interfaces pour un code flexible et extensible.

🎨 Abstraction

Classes abstraites et interfaces pour définir des contrats clairs entre composants.

🎓 Compétences Développées

💻 Développement Logiciel

Maîtrise de C# et du framework .NET pour créer des applications desktop robustes.

📐 Conception Logicielle

Analyse des besoins, modélisation UML et conception d'architecture logicielle.

✨ Bonnes Pratiques

Application des conventions de codage, documentation et principes de clean code.

🔧 Outils de Développement

Utilisation professionnelle de Visual Studio, Git et outils de débogage.
