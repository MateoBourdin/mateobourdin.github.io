📖 À propos du projet

Ce projet est une recréation du jeu classique "Zelda 2: The Adventure of Link" développé entièrement en Python. Le jeu utilise le terminal comme interface, avec des graphismes ASCII colorés et des animations en temps réel.

🎮 Gameplay Complet

Système de combat, exploration de carte, rencontres aléatoires, NPCs interactifs et boss à affronter.

🗺️ Monde Ouvert

Explorez différents biomes : plaines, forêts, déserts, grottes, temples et palais.

⚔️ Système RPG

Leveling, stats (vie, mana, attaque), objets à collecter et quêtes à accomplir.

🎨 ASCII Art

Graphismes ASCII détaillés avec couleurs ANSI pour une expérience visuelle rétro.

👾 Monstres Variés

Différents types d'ennemis avec des comportements d'IA uniques.

💬 NPCs Interactifs

Dialogues, quêtes secondaires et système de récompenses.

💻 Extraits de Code

Système de Joueur (Player.py)

import os
import sys

class Player: pass

def create(Name):
    player = Player()
    player.name = Name
    player.level = {"Player_xp": 0, "Xp_for_new_level": 50}
    player.stats = {"Life": 5, "Mana": 5, "Attack": 5}
    player.items = {"Candle": 0, "O": 0, "Village1_statue": 0}
    player.life = 20 * player.stats["Life"]
    player.active_life = player.life
    player.attack = 2 * player.stats["Attack"]
    player.pos = [26, 27]
    player.in_fight = False
    return player

🚀 Comment Lancer le Jeu

Prérequis

  • Python 3.x installé
  • Système Linux/Unix/MacOS (ou WSL sur Windows)
  • Terminal supportant les séquences ANSI
  • Terminal en plein écran recommandé

Installation et Lancement

# Cloner le repository
git clone https://github.com/MateoBourdin/ZeldaProject.git

# Naviguer dans le dossier du projet
cd ZeldaProject/"Projet IPI 2024"

# Lancer le jeu
python3 main.py

Pour Windows (WSL)

# Installer WSL
wsl --install

# Une fois dans WSL
cd /mnt/p/S1/Zelda/"Projet IPI 2024"
python3 main.py

🎓 Défis Techniques Relevés

🖥️ Rendu Terminal en Temps Réel

Gestion de l'affichage avec les séquences d'échappement ANSI pour positionner le curseur et afficher des graphismes colorés dans le terminal sans bibliothèque externe.

⌨️ Input Non-Bloquant

Utilisation de termios et select pour lire les entrées clavier sans bloquer la boucle de jeu, permettant une réactivité en temps réel.

🎮 Physique de Plateforme

Implémentation d'un système de gravité, de sauts et de collisions pour les combats en side-scrolling.

🗺️ Système de Monde Ouvert

Transition fluide entre la carte du monde et les scènes de combat, avec sauvegarde de position et gestion des différents biomes.
