À quoi sert un ORM, par rapport à du SQL direct ?What is an ORM for, compared with raw SQL?

On manipule des classes Python au lieu d'écrire du SQL. Avantages : code plus lisible, portabilité entre SQLite, PostgreSQL et MySQL en changeant seulement l'URL, intégration à Flask. Le coût : un léger surcoût (de l'ordre de la milliseconde).

We work with Python classes instead of writing SQL. Benefits: more readable code, portability between SQLite, PostgreSQL and MySQL by changing only the URL, Flask integration. The cost: a small overhead (around a millisecond).

Qu'est-ce que le problème N+1 et comment le code l'évite ?What is the N+1 problem and how does the code avoid it?

Sans précaution, afficher 200 artistes et leurs albums fait 1 requête pour les artistes plus 1 par artiste. selectinload(Artist.albums) charge tous les albums d'un coup avec un WHERE ArtistId IN (...) : 2 requêtes au total.

Questions qu'on peut nous poserQuestions we may be asked

Pourquoi une base de séries temporelles plutôt que du SQL ?Why a time-series database rather than SQL?

Les données IoT arrivent en continu, horodatées, en gros volume. InfluxDB est optimisé pour écrire vite et interroger par plage de temps, avec des agrégations comme aggregateWindow. Un SQL classique ferait pareil plus lentement et avec plus de place.

IoT data arrives continuously, timestamped, in large volumes. InfluxDB is optimised for fast writes and time-range queries, with aggregations like aggregateWindow. A classic SQL database would be slower and use more space.

Différence entre tag et field ?Difference between a tag and a field?

Un tag (location, symbol) est une étiquette texte indexée qui sert à filtrer et regrouper. Un field est la valeur mesurée (température, prix), non indexée. On filtre sur les tags, on calcule sur les fields.

A tag (location, symbol) is an indexed text label used to filter and group. A field is the measured value (temperature, price), not indexed. We filter on tags and compute on fields.

Comment la liste des villes du formulaire est-elle remplie ?How is the list of cities in the form filled?

With schema.tagValues(bucket: "weather", tag: "location"): InfluxDB returns every value of the tag. Same idea for currencies and cryptos.

À vérifier que le serveur InfluxDB répond avant de chercher plus loin quand une page est vide : réseau, URL ou token.

Sa cible est un score continu (25 à 346). Un classifieur traiterait chaque valeur comme une classe : précision proche de 0, sans sens. On utilise RandomForestRegressor avec le R² (environ 0,34). La version binaire (au-dessus ou en dessous de la médiane) donne une précision d'environ 72 %.

Its target is a continuous score (25 to 346). A classifier would treat each value as a class: near-zero, meaningless accuracy. We use RandomForestRegressor with R² (about 0.34). The binary version (above or below the median) gives about 72 % accuracy.

PW2 : pourquoi le modèle du cours a 89,9 % et une perte de 2,8 ?PW2: why does the course model get 89.9 % with a loss of 2.8?

Pas de normalisation (pixels 0–255, softmax saturé, erreurs commises avec une confiance totale) et pas de couche cachée (classifieur linéaire). Avec /255 et 512-256 + dropout, on atteint 98,3 %.

No normalisation (0–255 pixels, saturated softmax, mistakes made with full confidence) and no hidden layer (a linear classifier). With /255 and 512-256 + dropout we reach 98.3 %.

PW5 : pourquoi redimensionner la capture Google Earth ?PW5: why resize the Google Earth screenshot?

Un patch EuroSAT fait 64×64 pixels à 10 m, soit 640 m de côté. Une capture à 2,5 m/px montrerait seulement 160 m dans 64 pixels : des textures jamais vues. On ramène l'image à 10 m/px avant de découper.

A EuroSAT patch is 64×64 pixels at 10 m, i.e. 640 m wide. A 2.5 m/px screenshot would show only 160 m in 64 pixels: textures never seen in training. We rescale the image to 10 m/px before cutting.

Qu'est-ce qu'un Quadtree ?What is a Quadtree?

Un arbre où chaque nœud est un rectangle de la carte. Quand un rectangle contient plus de capacity points, il est coupé en 4 quadrants égaux, récursivement. Résultat : petites cellules là où c'est dense, grandes cellules vides là où il manque des stations.

A tree where each node is a rectangle of the map. When a rectangle holds more than capacity points, it is split into 4 equal quadrants, recursively. Result: small cells where it's dense, large empty cells where stations are missing.

Que change la capacité sur la figure ?What does the capacity change in the figure?

Plus elle est petite, plus l'arbre se divise et plus il y a de cellules. Les grandes cellules vides indiquent les zones sous-équipées où Velonecy peut ajouter des stations.

The smaller it is, the more the tree splits and the more cells there are. Large empty cells show under-served areas where Velonecy can add stations.

Pourquoi base64 plutôt qu'un fichier image ?Why base64 rather than an image file?

Rien n'est écrit sur le disque : pas de nom de fichier à gérer, pas de conflit entre deux utilisateurs, pas de nettoyage. L'image est dans la page HTML, sur la même page que le formulaire comme le demande le sujet.

Nothing is written to disk: no file names to manage, no conflict between two users, no clean-up. The image sits inside the HTML, on the same page as the form, as the brief requires.

Le premier nombre est le port du PC, le second celui de l'application dans le conteneur. Gunicorn écoute sur 5000 : le second doit rester 5000.

The first number is the host port, the second is the app's port inside the container. Gunicorn listens on 5000: the second must stay 5000.
