Les 12 pièges à relire

À relire en dernier, et encore une fois demain matin juste avant d'entrer.

  1. A * B multiplie élément par élément ; A @ B / np.dot font un produit matriciel.
  2. / donne un float (10/4 = 2.5), // le quotient (10//3 = 3), % le reste (10%3 = 1).
  3. La fin d'un slice et la borne de np.arange sont exclues. np.linspace inclut la fin.
  4. a[::2] part de l'indice 0 ; a[1::3] part de l'indice 1, puis 4, puis 7.
  5. Médiane : on trie avant. [7, 1, 3, 5] → [1, 3, 5, 7] → (3 + 5)/2 = 4.0.
  6. np.sqrt = racine, np.square = carré. Ne pas les inverser.
  7. axis=0 donne un résultat par colonne ; drop(…, axis=1) supprime une colonne.
  8. .loc = étiquette, .iloc = position.
  9. %timeit ne marche qu'en Jupyter et répète la mesure ; time.time() = une mesure, partout.
  10. PCA : standardiser d'abord, retirer la cible ; PC1 = plus grande variance ; composantes orthogonales.
  11. Learning rate trop grand → divergence ; on normalise x pour l'éviter.
  12. Accuracy trompeuse si les classes sont déséquilibrées : regarder aussi le recall. Scaler : fit sur le train seulement.
