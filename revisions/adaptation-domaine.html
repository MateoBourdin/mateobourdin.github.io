Adaptation de domaine

Faire marcher sur des données cible un modèle appris sur des données source d'apparence différente, pour la même tâche, avec peu ou pas d'étiquettes cible.

Sur téléphone, fais glisser la carte horizontalement.

La règle de base

Un modèle n'est fiable que sur des données distribuées comme son entraînement. Le domain shift, c'est l'écart entre les deux.

La question à se poser

Seul l'aspect des données change → adaptation de domaine. Ce qu'on prédit change → transfert inductif.

Le piège

Aligner les distributions ne garantit pas que les classes restent à leur place : quelques étiquettes cible lèvent le doute.
