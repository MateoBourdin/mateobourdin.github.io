Pipelines et qualité du code

Je ne livre pas sans vérifier : chaque modification passe par un pipeline automatique avant d’arriver en ligne.

🌐Le pipeline de ce portfolio

Chaque pull request sur le dépôt de ce site déclenche GitHub Actions. Le code n’est fusionné, puis publié sur GitHub Pages, que si toutes les étapes sont au vert.

  1. 🔀Pull requestune branche par modification
  2. ✅VérificationsHTML valide, traductions FR/EN complètes, liens internes et externes
  3. 🔐Secretstout l’historique Git scanné par gitleaks
  4. 🛡️SonarQube Cloudanalyse statique ; le check échoue si la Quality Gate n’est pas verte
  5. 🚀Déploiementfusion sur main, puis mise en ligne sur GitHub Pages
  • Analyse Sonar « secretless » : authentification OIDC, aucun token stocké dans le dépôt.
  • Actions GitHub épinglées par SHA de commit, pour une chaîne d’approvisionnement maîtrisée.
  • Novembre 2026 : 55 problèmes signalés par Sonar corrigés (dont une faille XSS), notes A en sécurité, fiabilité et maintenabilité.
